# 概览

Tenon 应用的组织方式。读完这几篇，就能看懂其余文档中的代码放在哪里、由谁创建。

- [Go 知识准备](go-primer.md)：context、错误的包装与判断、结构体标签等文档中常见的 Go 写法
- [目录结构](structure.md)：应用的目录约定，框架各个包的分层
- [应用生命周期](lifecycle.md)：启动、运行的部分、一次调用的 context、平滑停止与健康检查
- [依赖装配](dependencies.md)：在入口创建依赖，通过构造函数传给业务代码
- [业务动作](actions.md)：一个用例一个类型，同时供 HTTP、命令行和队列使用
