# 安装

安装 Tenon、在本地运行开发环境，以及部署到生产环境。

- [安装](installing.md)：认识 Tenon，从一个空目录写出最小的 API
- [脚手架](scaffolding.md)：用 `tenon init` 生成带前端的完整项目，并读懂生成的入口
- [开发工具](tooling.md)：`go tool tenon` 的 dev、build、generate 与 `tenon.json`
- [AI 编程助手](ai-assistants.md)：`AGENTS.md`、项目中的框架文档、依赖的文档和 MCP 服务，`tenon agents` 保持更新
- [部署](deployment.md)：构建、检查配置、迁移，用 systemd 或 Docker 运行，健康检查与平滑停止
- [交给客户自托管](self-hosting.md)：给客户的 compose 部署，第一次启动、升级、备份恢复和客户自己的数据库
- [自检](doctor.md)：部署前检查依赖的版本和设置、迁移和权限，每个问题附带修改方法
- [运维](operations.md)：不停机升级、维护窗口、PgBouncer、队列的监控与恢复、备份与恢复
